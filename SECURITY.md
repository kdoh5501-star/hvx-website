# Security policy

## Reporting a vulnerability

Please report security issues privately using GitHub's **"Report a vulnerability"** button on the
Security tab of this repository, or through the contact listed at `/.well-known/security.txt` on the
official website. Do not open public issues for security problems.

## Scope

- The official HIVE-X website (this repository).
- The HVX token contract `0x252Ce29d2a58B70f98fe80a67773747770Bb0028` and the vesting contract
  `0x04d4D102eed59b34A1A6527b48cCa690daEeC8a3` on BNB Smart Chain.

## Phishing and impersonation

HIVE-X never asks for a seed phrase, private key or a "verification" transfer. If you find a site,
account or token impersonating HIVE-X, please report it the same way.
